# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to singhabhinav1311@gmail.com. All security vulnerabilities will be promptly addressed.

Please include the following information in your report:
- Type of vulnerability
- Full path of the location of the vulnerability
- Any steps to reproduce the issue
- Any other technical details that might help

## Security Measures

This project implements several security measures:

1. Regular dependency updates using Dependabot
2. Code scanning with GitHub Actions
3. Secure coding practices
4. Regular security audits of dependencies

## Response Timeline

- Initial Response: Within 48 hours
- Update Frequency: Every 24-48 hours until resolution
- Resolution Timeline: Based on severity and complexity

Thank you for helping keep this project secure!
